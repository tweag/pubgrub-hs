# The UNSAT problem set: real Hackage packages that fail to resolve here, one
# problem per line. A problem is a comma-separated list of TARGETS, each
# "<package> [version-range]", solved together — see bench/problems.txt for the
# shape. Blank lines and #-comments are ignored; the reader splits on commas,
# never on whitespace, so nothing is quoted here.
#
#   cabal run pubgrub-harness -- --set corpus   # both solvers; writes bench/output/showcase.md
#   scripts/gate.sh                             # every problem, both solvers
#
# A comment carrying the word "showcase:exclude" keeps its problem in the corpus
# and the gate, run and measured by the harness, but out of the rendered showcase.
#
# Why a second file. bench/problems.txt measures the SEARCH — index throughput and
# conflict work — and its three unsat entries were found incidentally. These were
# found on purpose, by harvesting Hackage's own build reports for the releases
# where cabal itself failed to plan, and they exist to measure the EXPLANATION:
# every one of them has cabal's message for the same problem next to ours.
# docs/failure-cases.md holds the method, the failure kinds and the table.
#
# Two things to know before quoting any of these.
#
#  * They are pinned to THIS machine and THIS index. Four of the six failure kinds
#    depend on what the compiler provides (base 4.21, ghc 9.12.2) or on what
#    pkg-config can see — here libpq, libzmq, blas and lapack are ABSENT while
#    cairo, pango, gtk, zlib, libsodium and libgit2 are present. On a machine with
#    libpq installed, hpqtypes-extras resolves.
#  * cabal solves setup and build-tool depends (solveExecutables = True) and we do
#    not (rung 4 is unbuilt). On a package with a custom Setup.hs the two solvers
#    are answering different questions. None of the 17 below has one, but check
#    before adding.

# --- pkg-config: a C library this machine does not have -------------------------
# The most common kind among popular packages, and the one that exercises
# references/pubgrub.md:474 — every release in range is unbuildable, so the proof
# has to say so rather than call the range empty.
hpqtypes-extras ==1.20.0.0      # libpq. 2 lines against cabal's 7
haskoin-store-data ==1.6.0      # libsecp256k1, two hops down through haskoin-core showcase:exclude (fails for a different reason than cabal)
